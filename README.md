# 🔐 Gerador de Senhas

Um projeto desenvolvido em HTML, CSS e JavaScript para criar senhas aleatórias e avaliar sua força.

## 📌 Sobre o projeto

O Gerador de Senhas permite criar senhas personalizadas de acordo com as características escolhidas pelo usuário.

É possível definir:

- 🔠 Letras maiúsculas
- 🔡 Letras minúsculas
- 🔢 Números
- 🔣 Símbolos
- 📏 Tamanho da senha

O projeto também apresenta uma classificação da força da senha com base na sua entropia.

## ⚙️ Funcionalidades

- Geração automática de senhas aleatórias
- Escolha do tamanho da senha
- Seleção dos tipos de caracteres
- Classificação da senha em:
  - Fraca
  - Média
  - Forte
- Cálculo de entropia
- Estimativa do tempo necessário para descobrir a senha

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
